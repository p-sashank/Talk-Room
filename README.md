# 📌 Video Conferencing Application  

## 📝 Overview  
A full-stack, real-time video conferencing application designed to enable seamless and secure live communication. The platform allows users to join video/audio calls, exchange real-time messages, and share their screens. It also includes secure authentication and efficient handling of low-latency media streams.  

## ✨ Features  
- ✅ **Real-time Video & Audio Communication** – Low-latency calls powered by WebRTC.  
- ✅ **Secure User Authentication** – User registration and login with JWT-based authentication.  
- ✅ **Live Chat** – Real-time text messaging during calls.  
- ✅ **Screen Sharing** – Share your screen with other participants.  
- ✅ **Meeting History** – Track and revisit past sessions.  

## 🛠 Technology Stack  
This project leverages a modern, multi-tier architecture:  
- **Frontend:** React.js, Material-UI, Axios, React Router DOM  
- **Backend:** Node.js, Express.js  
- **Real-time Communication:** WebRTC, Socket.IO  
- **Database:** MongoDB   
- **Authentication:** JSON Web Tokens (JWT)  

## 🚀 Future Enhancements  
- 🔹 **Scalability:** Implement SFU (Selective Forwarding Unit) architecture to support larger meetings.  
- 🔹 **Meeting Recording:** Enable saving sessions for later review.  
- 🔹 **Breakout Rooms:** Facilitate smaller group discussions inside larger meetings.  
- 🔹 **Advanced Authentication:** Add password-protected meetings for enhanced security.
